One line, 117 characters: a city pigeon's elevator pitch to investors — a 10,000-courier delivery fleet paid in breadcrumbs, whose only churn is when a hawk eats middle management. A startup frame throughout (fleet, paid, churn) with a real punchline, and a voice that could only come from a pigeon.

## Run it

```sh
python3 main.py
```

It prints the line and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (and `/output/entry.txt` when different), validating the output byte-for-byte on read-back.
